# Diretrizes do Projeto

## 1. Padrões de Git & Workflow
- Criar Issues no GitHub para todas as tarefas (Correção, Melhoria, Feature).
- Gerenciar deploys via Pull Requests (PRs), mencionando a Issue correspondente.

## 2. Padrões de UI, Design & Taste Skill
- Seguir estritamente as diretrizes de direção de arte sem aspecto genérico/AI-made definidas no arquivo `SKILL.md` do repositório `Neto3x/taste-skill`.
- Aplicar Motion Principles: uso de skeletons, lazy loading, smooth animations e indicadores de progresso.

## 3. Arquitetura & Qualidade
- Garantir observabilidade, qualidade/lint de código e cobertura de testes.
